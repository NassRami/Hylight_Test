# TC-07 — UART Diagnostic Logging

## Objective

Verify that the STM32 periodically transmits a valid diagnostic packet over UART
using CRC16, COBS encoding and the `0x00` frame delimiter a t the end.


## Preconditions

- UART peripheral is initialized.
- The application is running normally.

## Test Steps

1. Connect the STM32 UART TX to the PC.

2. Start UART monitoring on the PC using a tool like `RealTerm`or an equivalent UART analyzer.

3. Run the firmware.

4. Observe the diagnostic UART frames.

5. Verify that a frame is transmitted approximately every **500 ms**

6. Verify that each frame ends with **0x00**

7. Remove the `0x00` delimiter and COBS-decode the received frame.

8. Verify that the decoded packet contains 11 bytes:

```text
Byte 0-1   : ΔP1
Byte 2-3   : ΔP2
Byte 4-5   : ΔP3
Byte 6-7   : Fan RPM
Byte 8     : Status Flags
Byte 9-10  : CRC16
```

9. Calculate the CRC16 over bytes `0` to `8`.

10. Compare the calculated CRC with bytes `9` and `10`.

11. Verify that the decoded diagnostic values correspond to the current
sensor, fan and system status values.
