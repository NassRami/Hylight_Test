# TC-02 — Sensor Switching

## Objective

Verify that the six BMP280 pressure sensors can be accessed correctly through
the TCA9548A I2C multiplexer.

## Preconditions

- I2C peripheral is initialized.
- `Sensors_App_Init()` has been executed.
- TCA9548A is connected to the STM32 I2C bus **(PA09 <----> I2C_SCL , PA8 <-----> I2c_SDA)**.
- All sensors are connected to TCA9548A channels 0 to 5.

## Test Steps

1. Initialize the sensor application using `Sensors_App_Init()`.
2. Call `Sensors_App_Process()`.
3. Verify that the application iterates from channel 0 to channel 5.
4. Verify that `BMP280_Mesure()` is called for each channel.
5. Verify that the corresponding TCA9548A channel is selected.
6. Verify that each BMP280 responds correctly.
7. Verify that valid pressure data is obtained from all six sensors.
8. Check the sensor fault state using `Sensors_App_Fault()`.
