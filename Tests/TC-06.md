# TC-06 — CAN TX

## Objective

Verify that the STM32 periodically transmits a valid diagnostic frame on the
CAN bus.

## Preconditions

- FDCAN peripheral is initialized.
- `CAN_Init()` has been executed.
- A CAN analyzer is connected to the CAN bus.
- The CAN analyzer uses the same CAN bitrate as the STM32.

## Test Steps

1. Power on or reset the STM32.

2. Start CAN bus monitoring using a CAN analyzer.

3. Verify that `CAN_Transmit()` is called periodically.

4. Observe the diagnostic CAN frames on the CAN analyzer.

5. Verify the CAN identifier.

6. Verify that the diagnostic frame contains the expected values:

```text
ΔP1
ΔP2
ΔP3
Fan RPM
```

7. Measure the time between two consecutive diagnostic CAN frames.

8. Verify that the transmission period is approximately **200 ms**
