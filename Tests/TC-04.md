# TC-04 — Fan Control 

## Objective

Verify  the fan can be controlled correctly through the MAX6650 in
automatic closed-loop mode and the  fan RPM is measured.


## Preconditions

- I2C peripheral is initialized.
- MAX6650 is connected to the STM32 I2C bus.
- The fan is correctly connected to the MAX6650.
- `Fan_APP_Init()` has been executed.
- The fan is not blocked or disconnected.

## Test Steps

1. Initialize the fan application using:

```c
Fan_APP_Init();
```

2. Set the fan to automatic mode:

```c
Fan_APP_SetMode(FAN_APP_MODE_AUTO);
```

3. Allow the fan enough time to start and stabilize.

4. Read the fan RPM:

```c
uint16_t fan_rpm = 0U;

Fan_APP_GetRPM(&fan_rpm);
```

5. Verify that the RPM value is valid and non-zero.

6. Execute:

```c
Fan_APP_Process();
```

7. Verify the fan fault state using:

```c
Fan_APP_Fault();
```
