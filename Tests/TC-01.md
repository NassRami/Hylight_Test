### TC-01 — CAN ID Detection

## Objectifs
Verify the CAN id during the initialization and reboot

## PReconditions
- CAN ID GPIO pins are configured as **Input Pull-Down**.
- Therefore, an unconnected GPIO is read as logic `0`and GPIO connected to VCC is read as logic `1`.
- A CAN analyzer is connected to the CAN bus.


## Test Steps
1. Set the GPIOs to a configuration
2. Power on the stm32
3. Observe that the CAN frame use the CAN ID configured using a CAN analyzer and a can visualizer frame (Canoe,busmaster ..)
4. Change the configuration of the GPIOs
5. Reset the stm32
6. Observe one more time the frame
