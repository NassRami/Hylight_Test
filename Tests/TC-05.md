# TC-05 — Fan Fault Detection

## Objective

Verify that the application correctly detects a fan fault ( blocked or hardware problem )


## Preconditions

- I2C peripheral is initialized.
- MAX6650 is operational.
- The fan is connected and initially operating normally.
- `Fan_APP_Init()` has been executed.
- The fan is in `FAN_APP_MODE_AUTO` or `FAN_APP_MODE_FORCE_ON`.
- The fan fault flag is initially cleared.

## Test Steps

1. Start the fan using automatic mode or forced ON mode.

```c
Fan_APP_SetMode(FAN_APP_MODE_AUTO);
```

2. Verify that the fan is running normally.

3. Verify that:

```c
Fan_APP_Fault() == false
```

4. Block or disconnect the fan.

5. Wait for the next fan monitoring cycle.

6. Execute:

```c
Fan_APP_Process();
```

7. Read the fan RPM.

```c
uint16_t fan_rpm = 0U;

Fan_APP_GetRPM(&fan_rpm);
```

8. Check the fan fault state:

```c
Fan_APP_Fault();
```

9. verify that
`STATUS_FAN_FAULT` is set.
