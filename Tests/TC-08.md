# TC-08 — UART Fan Control

## Objective

Verify that valid UART commands is  received correctly to control
the fan operating mode.


## Preconditions

- UART peripheral is initialized.
- MAX6650 is initialized.
- PC and STM32 use the same UART configuration.

## Test Steps

### Test 1 — FORCE ON

1. Send a valid UART frame containing:

```text
0x01
```

2. Execute:

```c
UART_Control_Process();
```

3. Verify that the application calls:

```c
Fan_APP_SetMode(FAN_APP_MODE_FORCE_ON);
```

4. Verify that the fan turns ON.

### Test 2 — FORCE OFF

1. Send a valid UART frame containing:

```text
0x02
```

2. Execute:

```c
UART_Control_Process();
```

3. Verify that the application calls:

```c
Fan_APP_SetMode(FAN_APP_MODE_FORCE_OFF);
```

4. Verify that the fan turns OFF.

### Test 3 — AUTO

1. Send a valid UART frame containing:

```text
0x03
```

2. Execute:

```c
UART_Control_Process();
```

3. Verify that the application calls:

```c
Fan_APP_SetMode(FAN_APP_MODE_AUTO);
```

4. Verify that the MAX6650 enters automatic closed-loop control mode.
